# IEC 61131-3 Overview

IEC 61131-3 defines standard PLC programming languages:

- **Ladder Diagram (LD)** — relay-style logic.
- **Structured Text (ST)** — Pascal-like procedural code.
- **Function Block Diagram (FBD)** — graphical blocks.
- **Instruction List (IL)** — low-level mnemonic style.

PLCAutoPilot IR captures ladder-oriented networks and analog/function-block nodes (timers, counters, compare, PID) and serializers emit vendor-specific text for export.

When describing logic, name inputs/outputs clearly so the IR symbol table maps cleanly to your physical I/O.
